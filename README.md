# ColorOS 唤语

在 ColorOS 国内版上还原 AOSP 的数字助理行为。

国内固件把「唤醒数字助理」的三个入口改写成了自家小布助手，并让这些路径绕开 AOSP 的助理分派：长按电源键固定启动小布，长按手势条固定触发小布识屏，屏幕底部角落内滑干脆不派发。本模块不替换系统的助理栈，只在被改写的那几个分派点上把请求交还给系统当前设置的默认助理应用（`Settings.Secure.assistant` 指向的应用）。

它不是一个新的助理应用。安装并启用后，你仍然使用原来习惯的那三个入口。

## 能做什么

- 长按电源键、长按手势条、屏幕底部角落内滑，三个入口都唤醒系统当前设置的默认助理。
- 每个入口可以单独选择目标：跟随系统默认助理、一圈即搜、小布识屏、小布助手，或自定义组件。
- 每个入口也可以单独关闭；关闭后连 OEM 自己的调用一起压掉，不再偷偷唤起小布。
- 为长按手势条补齐国内固件缺失的一圈即搜系统服务链路。
- 解除设置等页面的底角手势限制，这些页面也能用底角内滑。
- 长按手势条时不再白唤醒一次小布识屏服务。
- 在系统冻结决策处豁免 Google 应用，减少「派发成功但屏幕没反应」。
- 长按电源键的震动反馈保持开启，与 OEM 原始行为一致。

## 环境要求

- ColorOS 国内版固件，已在 ColorOS 16（`V16.1.0`，机型 PJZ110）上验证。
- KernelSU 或 Magisk 等 Root 方案。
- LSPosed 等支持 libxposed API 102 的框架。

## 安装

1. 安装本页 Release 里的 APK。
2. 在 LSPosed 中启用「ColorOS 唤语」，作用域勾选 `system`、`com.android.systemui`、`com.android.launcher`、`com.google.android.googlequicksearchbox` 四项，缺少任意一项对应功能不会生效。
3. 重启设备。
4. 打开「ColorOS 唤语」，在「入口」页确认模块状态为已生效，再按需调整三个入口。

## 使用

- 「入口」页显示模块状态、当前系统默认助理（点击可直接跳转系统助理设置）、三个唤醒入口和一个总开关。
- 「唤醒目标」页按入口分页，每个入口独立设置唤醒谁。
- 「高级」页可以跳过识屏服务预绑定、解除页面级手势限制、开启 Google 应用机型伪装。

## 注意

- 系统的语音交互会话同一时刻只认一个助理应用，这是平台本身的约束，所以「自定义组件」能否弹出界面取决于目标应用自身。
- 同一手势不要与其它接管类模块（例如 Oplus-Assistant-Hook）同时启用，先接管的一方会直接返回。
- 如果日志里出现派发记录但屏幕没有任何反应，通常是助理进程被系统冻结或回收，把该应用设为允许后台运行、关闭权限自动回收后再试。

源码、构建说明与排错细节见 [ColorOS-Assistant-Restore](https://github.com/Andrea-lyz/ColorOS-Assistant-Restore)。
